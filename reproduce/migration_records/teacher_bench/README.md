# 教师模型对比（验证集，2026-10-14）

数据：验证集 41 个扫描（20 个物理场景，均来自 ScanNet 官方训练集，不在任何测试集中），按 SIU3R 训练采样规则
（第二帧在 10–100 帧之后、iou.pt ∈ (0.3, 0.8)、固定种子）每扫描 5 组，共 205 组 / 410 帧。GT 为 SIU3R 的 2D 实例图
（18 个 thing 类，墙/地板/未标注区域作忽略区）。代码 `scripts/teacher_bench/`，各方法分数 `*.json`。

| 教师 | 单帧 AP | 单帧 AP50 | AR100 | 双视角 AP（全局 ID） | 双视角 AP50 | mCov | 跨视角 ID 一致率 | 类别 AP50 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| SAM2.1 自动分割（单帧） | 0.141 | 0.256 | 0.236 | 0.023 | 0.083 | 0.376 | 0（无跨帧 ID） | — |
| SAM2.1 视频传播 | 0.131 | 0.258 | 0.245 | **0.124** | **0.253** | 0.414 | **0.976** | — |
| Grounded-SAM（阈值 0.3） | 0.189 | 0.397 | 0.267 | 0.021 | 0.086 | 0.401 | 0 | 0.342 |
| Grounded-SAM（阈值 0.2） | **0.210** | **0.449** | **0.307** | 0.024 | 0.100 | **0.475** | 0 | **0.366** |
| MaskClustering（SAM2.1 掩码 + GT 深度/位姿） | 0.116 | 0.233 | 0.222 | 0.083 | 0.179 | 0.339 | 0.972 | — |

指标：单帧 AP 每帧单独算（类无关 COCO mask AP）；双视角 AP 把两帧拼成一张图、用教师自己的 ID，跨视角换 ID 会被判错
（与 SIU3R 的全局 ID 评测同理）；mCov 为每个 GT 物体的最佳 IoU 平均；一致率 = 两视角都匹配上（IoU≥0.5）的物体中 ID 相同的比例。

实现说明：MaskClustering 官方代码未改算法；CropFormer 权重已下架，2D 输入换成 SAM2.1；SIU3R 数据无 mesh，
场景点云用全部帧 GT 深度融合（2 cm 体素）；pytorch3d.ball_query 换为等价的 torch 实现（已与暴力解逐项核对一致）。
SAM2 视频：c1 自动分割种子 → 传播到 c2（≤16 帧）→ 补 c2 新物体 → 反向传播，分数用种子掩码的 predicted IoU。
